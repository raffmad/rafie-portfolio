# Rafie Ahmad Anwari — Editorial Portfolio

Portofolio statis berbasis HTML, CSS, dan JavaScript dengan layout editorial asimetris, panel berbingkai, aksen oranye, dan tampilan responsif.

## Menjalankan
Buka `index.html` di browser atau gunakan ekstensi Live Server.

## Deploy GitHub Pages
Unggah isi folder ini ke root branch `portfolio-editorial` pada repository `raffmad/rafie-portfolio`. GitHub Pages yang sudah dikonfigurasi akan menerbitkan perubahan dari branch tersebut.

## Catatan
- Tidak memerlukan build step atau backend.
- Font menggunakan Google Fonts; bila offline, browser memakai fallback.
- Visual hero, proyek, dan panel foto dibuat dengan CSS sehingga tidak memerlukan aset gambar eksternal.
