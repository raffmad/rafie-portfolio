# Rafie Ahmad Anwari — Portfolio

Website portofolio personal dengan gaya **Editorial Awwwards**: latar charcoal, aksen oranye, tipografi besar, layout editorial asimetris, dan responsif untuk perangkat mobile.

## Teknologi
- HTML5
- CSS3
- JavaScript vanilla
- Google Fonts (Manrope & DM Mono)

## Menjalankan secara lokal
Cukup buka `index.html` di browser. Untuk pengalaman pengembangan, jalankan Live Server dari VS Code.

## Deploy
Repository ini dapat dipublikasikan melalui GitHub Pages:
1. Buka **Settings → Pages**.
2. Pilih **Deploy from a branch**.
3. Pilih branch `main` (atau branch hasil review) dan folder `/root`.
4. Simpan, lalu tunggu URL Pages tersedia.
